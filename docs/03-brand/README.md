The Operating System for Meal Prep & Catering

## First customer brand

**EatClean Tenerife** — tenant-specific branding via `tenants.brand` JSON. Platform chrome stays YourMeal OS; tenant surfaces may inject `--brand-primary` and related tokens from `brand`.
