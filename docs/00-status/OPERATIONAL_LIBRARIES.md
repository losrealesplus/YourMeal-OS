```text
Libraries are not where work happens.
Libraries are where knowledge is reused.
```

---

## Why this exists

Without a shared concept, every catalog becomes an admin CRUD screen.

With it:

* Experiences **consume** libraries during operational work  
* CRUD stays bootstrap / Capability substrate  
* Operators stay in the journey (call · week · route)

## Rules

1. A library is **consumed inside an Experience**, not opened as the day’s workplace.  
2. Creating catalog entries is secondary; **finding and reusing** is primary.  
3. Empty library → clear path to create **then return** to the journey.  
4. Accelerators (Import · Bulk · Templates) may **fill** libraries after evidence — they do not redefine them.  
5. No new Capability is required to name a library — naming guides Experience design.
