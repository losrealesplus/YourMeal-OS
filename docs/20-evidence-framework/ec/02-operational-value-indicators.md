# Operational Value Indicators (OVI)

Indicadores con los que EC mide el valor del **conocimiento** (y, por extensión, de las Capabilities que lo implementarán).

---

## Catálogo inicial (YourMeal OS / EatClean)

| ID | Indicador | Dimensión | Unidad sugerida | Cómo se captura |
|----|-----------|-----------|-----------------|-----------------|
| **OVI-01** | Tiempo de planificación | A | min / día o semana | Cronómetro · entrevista estructurada |
| **OVI-02** | Cambios manuales (amend / replan) | A · C | nº / semana | Conteo en ventana FOV |
| **OVI-03** | Errores operativos | B | nº / semana | Incidentes · etiquetas mal · plato equivocado |
| **OVI-04** | Retrabajo | A · B | min o ciclos / semana | Doble cocción · reetiquetado · reentrega |
| **OVI-05** | Incidencias (ruta / entrega / cobro) | B · C | nº / semana | Log de excepciones |
| **OVI-06** | Preguntas repetidas al responsable | C | nº / día | Observación FOV |
| **OVI-07** | Decisiones que dependen de memoria | C | cualitativo → escala 1–5 | Entrevista |
| **OVI-08** | Coste de onboarding nueva cocina / cliente | D | horas · repetición de diseño | Estimación con método |
| **OVI-09** | Variantes de producto sin romper Core | D | nº absorbidas / Core Δ | Trazas SF/FO-E |

OVI-01…05 son el **núcleo** de la primera EC.  
06–09 refuerzan Consistencia / Escalabilidad.

---

## Ficha OVI (plantilla)

```markdown
# OVI-0x — [Nombre]

**Dimensión:** A · B · C · D  
**Definición:** …  
**Unidad:** …  
**Baseline (antes):** valor · fecha · método  
**Target / umbral EC:** …  
**Fuente de datos:** FO · entrevista · contador  
**Capabilities relacionadas:** …
```
