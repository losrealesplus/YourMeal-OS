# ADR 0099 — EXPERIENCE MANIFESTO 001

## Estado

**Accepted** — 2026-08-07  
**Track:** Era 2 · Experience constitution  
**Detalle:** [EXPERIENCE_MANIFESTO](../00-status/EXPERIENCE_MANIFESTO.md)  
**Depends on:** EXPERIENCE LAW 001 (ADR 0098) · PRODUCT LAW 001 · 002 · TEAM LAW 001 · TENANT SUCCESS LAW 001

## Contexto

Laws define filters. Missions define TTA. Missing was the **mission philosophy** of an Experience: software that disappears so the operator thinks about the customer.

## Decisión

1. Accept **EXPERIENCE MANIFESTO 001**:

```text
A great Experience is invisible.
The operator should think about the customer,
not about the software.
The software succeeds when it disappears.
```

2. Publish [EXPERIENCE_MANIFESTO.md](../00-status/EXPERIENCE_MANIFESTO.md).  
3. Require Experience prompts written as **missions**, not task lists.  
4. Require first screen to ask one decisive question (not open empty).  
5. Require **Operational Time Saved** block on every Experience PR.  
6. Sin Architecture / Engine / new Capability changes.

## Consecuencias

- Experience work judged by invisibility + seconds returned.  
- PR template and Review Protocol check Operational Time Saved.  
- Customer Experience 001 is the first Manifesto-aligned mission.
