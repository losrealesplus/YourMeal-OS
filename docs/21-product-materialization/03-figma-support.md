# Figma — herramienta de apoyo

**No** es el centro del flujo YourMeal OS.  
Lovable + repo son el camino principal de materialización UI.

---

## Cuándo sí usar Figma

| Caso | Por qué |
|------|---------|
| Interacción compleja (gestos, estados densos) | Explorar antes de pedirlo a Lovable |
| Componente muy específico | Precisión visual / DS |
| Prueba de usabilidad pre-implementación | Prototipo rápido sin ensuciar repo |
| Documentar patrón del Design System | Referencia estática |

---

## Cuándo no

- Dibujar **todas** las pantallas antes de Lovable  
- Convertir Figma en fuente de verdad de producto (gana `docs/` + OM + matriz)  
- Diseñar features no ancladas al Operational Model
