# WORKAROUNDS — Trucos manuales

## Propósito

Todo truco manual es una **oportunidad latente**.

No proponemos solución aquí. Solo registramos el parche humano.

## Alcance

Post-its, Excel paralelos, grupos de WhatsApp, «avisar a fulano», códigos de colores improvisados, etc.

## Estructura

```text
WA-XXX

Fecha:
Empresa:
Área:
Persona / rol:

Workaround observado:
Motivo aparente:     (por qué existe el truco — hecho, no diseño)
Qué problema tapa:
OF relacionados:
Estado: Activo | Sustituido | Descartado
```

## Reglas

- Prohibido escribir «deberíamos hacer un módulo…».  
- El workaround es evidencia de un hueco; el diseño viene después del patrón.

## Criterios de actualización

Cuando se vea un truco nuevo o deje de usarse.

## Ejemplo

```text
WA-001

Fecha: 2026-07-21
Empresa: EatClean (ejemplo de plantilla)
Área: Compras / cocina
Persona / rol: Encargada

Workaround observado:
La encargada pone un post-it amarillo cuando falta pollo.

Motivo aparente:
No existe un aviso automático (según lo observado / relatado).

Qué problema tapa:
Riesgo de olvidar reponer / descongelar a tiempo.

OF relacionados: —
Estado: Activo (ejemplo — validar en campo)
```
