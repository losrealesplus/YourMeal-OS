**Documento:** `PS-002.md`

**Modo de prueba:** Bootstrap Identity (no rediseña Auth producción)

## Objetivo

Smoke de autenticación / identidad: login, logout, cambio de rol, sin doble `getSession`, sin loops.

## Procedimiento

1. Estático: `SupabaseIdentityProvider` sin `getSession()` paralelo; root filtra `TOKEN_REFRESHED`.  
2. Bootstrap: Entrar como Company Admin → panel DEV MODE.  
3. Cambiar perfil a Kitchen → restaurar Company Admin.  
4. **Salir** → selector de perfil (análogo logout).  
5. Re-entrar.

## Resultado

| Chequeo | Valor |
|---------|-------|
| Sin dual `getSession()` | PASS |
| Root no invalida en TOKEN_REFRESHED | PASS |
| Login Bootstrap → DEV MODE | PASS |
| Switch Kitchen / restore Admin | PASS |
| Salir → selector | PASS |
| **Gate** | **PASS** |

### Notas

Ruidos de red 401/404 hacia Supabase con token sintético Bootstrap son **esperados** y se excluyen del umbral de errores JS. Auth de producción (email/password real) no se reabre aquí — Identity Freeze / Foundation Lock permanecen.
